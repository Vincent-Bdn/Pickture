Install

One file. No installer.

Pickture is a single executable. Nothing is registered, no runtime is needed, and removing it is deleting the file.

Download for Windows

Windows 10 and 11, 64-bit. Around 10 MB.

First run

Windows may warn that it does not recognise the program. That is SmartScreen reporting that the file is not signed by a certificate I have paid for, not that anything is wrong with it — choose More info, then Run anyway. If you would rather not take my word for it, the section below builds the same program from source.

Pickture then asks for a folder of photographs. There is no wizard, no account and nothing to configure. Folders you have opened before appear on that first screen with how far through them you got.

Building from source

You need Rust. Nothing else — the fonts and the icon are compiled into the binary, and there are no system libraries to install. 

git clone https://github.com/Vincent-Bdn/pickture
cd pickture
cargo run --release

The finished binary is at target/release/pickture.exe and can be moved anywhere. To check the build before trusting it: 

cargo test --workspace

macOS and Linux are not tested, but nothing in the code is Windows-specific and the same commands should work.

Where Pickture keeps things

What Where
Your photographs Exactly where you left them. Pickture opens them read-only and never writes to them.
Keepers selection/ beside your photographs by default, or wherever you point it. Copies, never moves.
Sessions %APPDATA%\Pickture\config\sessions.json — which folders you have opened, where you stopped, what you kept. Plain JSON. Safe to delete.
Thumbnail cache %LOCALAPPDATA%\Pickture\cache — rebuilt on demand. Safe to delete at any time.

To uninstall: delete pickture.exe, and the two folders above if you want the record gone too. There is no uninstaller because there is nothing registered to undo.

Supported formats

JPEG, PNG, TIFF, BMP, GIF and WebP. Raw files are not supported yet — if you shoot ARW, CR3, NEF or DNG, Pickture will not see them in the folder. That is the largest thing missing, and it is stated here rather than discovered after downloading.

To be precise about a word this page deliberately avoids: because of that restriction Pickture is source available, not open source. The Open Source Definition does not allow a licence to discriminate between fields of use, and a noncommercial clause does exactly that. The source is public and you can read every line of it — but calling it open source would be inaccurate.
